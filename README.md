# Todo — Beautifully Simple

A frontend-only todo app built with **React + TypeScript + Vite + Tailwind CSS**.

## Features

- Add, complete, edit (double‑click), and delete todos
- Filters: All / Active / In Progress / Completed
- Search (task + report-to)
- Columns: **To be completed by** (due date) and **Report to**
- Persists to `localStorage`
- Theme toggle: system → light → dark

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
